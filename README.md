## 🏠 Buganza Imóveis

**Sistema web para gerenciamento e apresentação de imóveis.**

Aplicação full stack desenvolvida para uma imobiliária, com catálogo público e estrutura administrativa para gerenciamento dos imóveis.

**Stack:** Next.js • TypeScript • Prisma • PostgreSQL • Supabase

**Destaques:**

* 🏠 Catálogo de imóveis
* 🔐 Autenticação e área administrativa
* 🖼️ Gerenciamento de imagens e vídeos
* 🔎 Busca e filtros
* 📱 Interface responsiva
* 💬 Integração com WhatsApp
* 🗄️ Persistência em PostgreSQL

🔗 **[Ver repositório](https://github.com/romavitordev/buganza_imoveis)**
